# Stampcheck

Free email HTML checker: https://getstampcheck.com

Paste an email's HTML and see what breaks in Gmail, Outlook, Apple Mail and on phones before you send. Everything runs in the browser; nothing is uploaded.

## Files

- `index.html` – the whole app in one file (editor, checks, previews, fonts)
- `og.png` – social sharing image
- `robots.txt`, `sitemap.xml` – search engine files
- `CNAME` – custom domain for GitHub Pages
