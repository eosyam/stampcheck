SVG images in email: why they don't show in Gmail and Outlook

By Eray, who builds Stampcheck · Published 4 November 2026

Short answer: Gmail and Outlook don't display SVG images, whether linked or inline. Export your logos and icons as PNG at twice the size you display them, and set the display size with the width attribute so they stay sharp on high-resolution screens.

The fix

  1. Export the SVG as a PNG at 2× the display size: a logo shown at 150 px wide becomes a 300 px PNG.
  2. Set the display size with the width attribute (and height if you know it), not only with CSS.
  3. Add alt text, because many readers see emails with images off.
<img src="https://example.com/logo@2x.png" width="150" alt="Acme" style="display:block;border:0;">

What about WebP?

WebP and AVIF are smaller, but support in email clients is still patchy, so some readers would see a blank space. PNG and JPEG work everywhere; use GIF only for simple animation, and remember Outlook for Windows shows only the first frame.

Frequently asked questions

Does Apple Mail show SVG?

Yes, but Gmail and Outlook don't, so SVG isn't safe for an email most people will open there.

Why use the width attribute instead of CSS?

Outlook ignores CSS width on images and shows them at their real pixel size, so a 2× image would appear twice as big.

Should my logo be PNG or JPEG?

PNG for logos and icons with sharp edges or transparency; JPEG for photos.
