Why gradient backgrounds disappear in Outlook (and what to do)

By Eray, who builds Stampcheck · Published 4 November 2026

Short answer: classic Outlook ignores CSS gradients such as linear-gradient(), so the area behind your text turns blank, often white. Always set a solid background-color (and the bgcolor attribute) that works with your text on its own. If the gradient really matters in Outlook, draw it with VML.

Step 1: a solid fallback every client understands

<td bgcolor="#1D44B8"
    style="background-color:#1D44B8;background-image:linear-gradient(135deg,#1D44B8,#4C7CF0);color:#ffffff;">
  Big announcement
</td>

Outlook shows the solid blue, everyone else the gradient. Pick a fallback close to the gradient's main color so the text stays readable.

Step 2 (optional): a VML gradient for Outlook

VML can draw a gradient fill inside an Outlook-only block. It needs fixed dimensions and the VML namespace, and it adds code to every email, so use it only where the gradient carries the design.

<!--[if mso]>
<v:rect xmlns:v="urn:schemas-microsoft-com:vml" fill="true" stroke="false" style="width:600px;height:200px;">
  <v:fill type="gradient" color="#1D44B8" color2="#4C7CF0" angle="135"/>
  <v:textbox inset="0,0,0,0">
<![endif]-->
  …content…
<!--[if mso]>
  </v:textbox>
</v:rect>
<![endif]-->

Frequently asked questions

Do gradients work in Gmail and Apple Mail?

Yes, CSS gradients work in most clients except classic Outlook.

Why is my text unreadable in Outlook?

The gradient is gone, so light text sits on the default white background. A dark fallback color fixes it.

Is VML worth it?

Only when the gradient is central to the design. A good solid fallback is enough for most emails.
