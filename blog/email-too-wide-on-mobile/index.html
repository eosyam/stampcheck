Email too wide on mobile? Why it scrolls sideways and how to fix it

By Eray, who builds Stampcheck · Published 6 November 2026

Short answer: an email scrolls sideways on a phone when something inside it has a fixed width larger than the screen, most often a width="600" table, an image without max-width, or a long unbroken link. Make widths a maximum instead of a fixed size (width:100%; max-width:600px), keep a fixed-width table only for Outlook, and let long text wrap.

Why it happens

Most emails are designed at 600 to 640 px, while phones are usually 320 to 430 px wide. If any element refuses to shrink, the whole email becomes as wide as that element. Depending on the app, readers then have to scroll sideways, or the app scales the entire email down until the text is too small to read. Either way, people tend to give up.

The usual culprits:

  • Fixed-width tables. A wrapper like <table width="600"> stays 600 px on every screen unless something overrides it.
  • Images sized in pixels only. An image with width="600" and no max-width:100% pushes the layout out.
  • Columns that don't stack. Two or three side-by-side table cells with fixed widths add up to more than the screen.
  • Long unbroken strings. A raw tracking URL, a long email address or a coupon code with no spaces can't wrap.
  • min-width and white-space: nowrap. Both stop content from shrinking or wrapping.
  • No viewport meta tag. Without it, some mobile apps lay the email out as if the screen were wider and then zoom out.

How to fix it, step by step

  1. Find the element that sticks out. Open the email at phone width and look for whatever reaches past the right edge. It is often a single image or table, not the whole layout.
  2. Turn fixed widths into maximums. Give the main container width:100%; max-width:600px instead of a fixed 600 px.
  3. Keep a fixed width for classic Outlook. Outlook for Windows ignores max-width, so wrap the container in an Outlook-only table that holds it at 600 px there. More on that in why emails break in Outlook.
  4. Make images fluid. Keep the width attribute for Outlook, and add width:100%; max-width:600px; height:auto in the style. See why images show up huge in Outlook for why the attribute matters.
  5. Let long text wrap. Add overflow-wrap:anywhere; word-break:break-word to cells that hold links or codes, or replace raw URLs with short link text.
  6. Stack columns on small screens. Use a media query to make column cells full width, or build columns as inline-block elements that wrap on their own when there isn't room.
  7. Add the viewport tag in the <head>: <meta name="viewport" content="width=device-width, initial-scale=1">.

Copy-paste starting point

A container that is 600 px on desktop, fits a phone, and stays 600 px in classic Outlook:

<!--[if mso]>
<table role="presentation" width="600" align="center" cellpadding="0" cellspacing="0" border="0"><tr><td>
<![endif]-->
<table role="presentation" width="100%" cellpadding="0" cellspacing="0" border="0"
       style="width:100%; max-width:600px; margin:0 auto;">
  <tr>
    <td style="padding:24px; overflow-wrap:anywhere; word-break:break-word;">
      <img src="https://example.com/hero.jpg" width="600" alt="Spring sale"
           style="display:block; width:100%; max-width:600px; height:auto; border:0;">
      <p style="font:16px/1.5 Arial, sans-serif;">Your content here.</p>
    </td>
  </tr>
</table>
<!--[if mso]>
</td></tr></table>
<![endif]-->

And a media query to stack two columns on phones. Add the class col to each column cell:

<style>
  @media (max-width: 620px) {
    .col { display:block !important; width:100% !important; }
  }
</style>

Treat the media query as an improvement, not the only fix. Support for style blocks and media queries varies between mobile apps and account types, so the base layout should already fit without it.

Frequently asked questions

What width should an HTML email be?

Most emails are designed at 600 to 640 px for desktop. That is fine as long as the width is a maximum, not a fixed size, so the email can shrink to fit a phone that is 320 to 430 px wide.

Why does my email look fine on desktop but scroll sideways on my phone?

Something inside it has a fixed width larger than the phone screen: usually a 600 px table, an image without max-width, a long unbroken link, or columns that don't stack.

Do I still need media queries?

They help with stacking columns and adjusting padding, but not every mobile app applies them in every setup. Build the email so it fits without them, and use media queries as an improvement on top.

Will Outlook break if I use width 100% and max-width?

Classic Outlook for Windows ignores max-width, so the email can stretch across the window. Wrap the content in an Outlook-only table with a fixed width, as shown above, to keep it at 600 px there.
