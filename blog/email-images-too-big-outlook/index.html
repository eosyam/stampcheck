Why images show up huge in Outlook (and how to fix it)

By Eray, who builds Stampcheck · Published 4 November 2026

Short answer: classic Outlook ignores CSS width and max-width on images and shows them at their actual pixel size. A 1200 px image meant to display at 600 px fills the screen. Set the HTML width attribute to the display size.

The fix

<img src="https://example.com/hero@2x.jpg" width="600" alt="Spring sale"
     style="display:block;width:100%;max-width:600px;height:auto;border:0;">
  • width="600" is what Outlook uses.
  • width:100%; max-width:600px; height:auto let the image shrink on phones in other clients.
  • Use an image twice the display width for sharpness on high-resolution screens; the width attribute keeps it at the right size.

Related: high-DPI scaling

On Windows with display scaling (125%, 150%), Outlook can scale images and layouts differently from text. Fixed widths in the HTML attributes, rather than only in CSS, keep things in proportion.

Frequently asked questions

Why does the image look right everywhere except Outlook?

Other clients follow your CSS. Classic Outlook uses Word's engine, which ignores CSS sizes on images.

Should I resize the image file itself instead?

You can, but a 2× image with a width attribute looks sharper on modern screens.

Do I still need CSS sizes?

Yes, for mobile: width:100% and height:auto make the image shrink on small screens in other clients.
