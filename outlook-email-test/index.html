What Outlook breaks, and what this test catches

Classic Outlook for Windows renders email with Microsoft Word's engine, not a browser. Stampcheck checks your HTML against the problems that causes:

  • Layouts: flexbox, grid and widths on <div>s that Outlook ignores, and max-width containers that stretch across the whole window.
  • Buttons: rounded buttons that turn into flat links, and padding that disappears.
  • Backgrounds: gradients and background images that don't show.
  • Images: pictures that blow up to full size, GIFs that only show their first frame, and scaling on high-DPI screens.
  • Fonts: web fonts without a fallback, which can turn into Times New Roman.
  • VML: Outlook-only code that is missing its namespace and silently fails.

How to use it

  1. Open Stampcheck with Outlook selected using the button below.
  2. Paste your HTML or open the file. Exports from Mailchimp, Klaviyo, HubSpot or MJML all work.
  3. Fix what is marked will break first, then may look wrong. Each issue shows the line and the fix.

The Outlook preview is an approximation of classic Outlook for Windows, and the page says so. For an important send, do one final test in a real Outlook inbox.

Frequently asked questions

Is this a real Outlook render?

No. It is an approximation built from Outlook's known rules, plus checks that point at the exact code Outlook drops. It catches most problems before you need a real inbox test.

Does it test the new Outlook for Windows?

The checks target classic Outlook for Windows, which causes almost all Outlook rendering problems. The new Outlook renders close to Outlook on the web.

Is my email uploaded anywhere?

No. The check runs entirely in your browser.

Is it free?

Yes. An optional paid feature fixes the issues it finds and checks the result again.
